> 这是粥左罗第三期读书会的第二本书。这本书虽然没有《乔布斯传》名气大，但也能从另一个角度来了解乔布斯。

## 一、概述

《成为乔布斯》讲的是一个狂妄、被赶出苹果的年轻人，怎样成长为史上最高效、最有远见的商业领袖。它不重复"天才加混蛋"这类老说法，而是写出一个真实的乔布斯：他把与生俱来的激情和慢慢学会的成熟管理结合起来，一边把优点发挥到极致，一边和自己的缺点较劲。最后他打造出史上最有价值、最受消费者追捧的公司，也改变了几十亿人的生活。

作者布伦特·施兰德和乔布斯认识了25年，采访过他很多次。书里还有库克、艾维、卡特穆尔等身边人的一手讲述，家庭和事业都写到了。作者认为，乔布斯在苹果的成功不只是因为选对了产品，更是因为他变得更有耐心、全心信任核心团队，让公司一步步稳着发展，而不是把希望押在几件一鸣惊人的产品上。

## 二、金句摘抄

### 2.1、人的成长：优点和缺点是同一枚硬币

**核心：乔布斯不是天生的完美领袖，而是在失败里慢慢学会管理自己的天赋和缺陷。**

+ 史蒂夫最大的优点与最大的弱点不可避免地交织在一起。优点造就了麦金塔，弱点让他被逐出苹果、让 NeXT 失败。
+ 我们穷尽一生与自身的天赋和缺陷做斗争，学着如何去管理它们。
+ 只有经历了这些不成熟，他重回苹果后才会变得头脑清晰、脾气温和、不断反思、始终如一。
+ 对于 30 岁的年轻人来说，进行反思并不是一件容易的事；承认错误对史蒂夫来说非同寻常。
+ 他不是故意尖酸刻薄，只是缺乏与人相处的技巧。
+ 没有在皮克斯的这段经历，就不可能有苹果的第二次辉煌。
+ 你必须把自己的尊严和观点分开来看，否则就没办法学习进步。
+ 他一直在改变，直到离开人世的那一刻。
+ 性格只是外在因素，更重要的是你能否不断成长，从失败与挫折中重新站起来。

### 2.2、产品观：追求完美，专注，整合

**核心：公司只是手段，打造伟大的产品才是目的，而完美是一个永远做不完的过程。**

+ 对于一个橱柜来说，别人看不到的底面与表面的抛光一样重要。
+ 完美是一个渐进持续的过程，永远都不可能彻底完成。
+ 关键不是做得有多快，而是做到最好；情愿错过截止日期，也不能粗制滥造，但真正的艺术家必须让产品上市。
+ 他能将不同的观点与技术进行整合，让整体远大于部分之和。
+ 如果无法把注意力聚焦在某一点上，就无法给公司确立清晰的目标。
+ 最好的办法是在上一个产品到达巅峰时，下一个产品已经蓄势待发。
+ 伟大的产品都是不断试错的结果。
+ 创建公司唯一的目的就是打造产品；成功与否主要看我们是否对自己打造的产品感到自豪。
+ 永不满足比野心或智慧更重要，它的根源是好奇心。

### 2.3、团队与管理：找最好的人，然后放手

**核心：一流人才是公司最大的财富，好的管理是倾听和放手，而不是事事称心。**

+ 你们应该找最优秀的人，不能退而求其次；一位杰出人才远不止顶两个普通人。
+ 把合适的人招进来只是开始，关键在于让公司公开透明。
+ 最好的管理技能就是放手，给优秀人才足够的空间。
+ 如果你想要成功，就得听听部下的想法；周围都是聪明人，你就会倾听。
+ 最优秀的团队成员会用事实和能力挑战史蒂夫，最终赢得他的尊重。
+ 不要在意他大吼大叫本身，要搞清楚他为什么吼，那才能帮你解决问题。
+ 如果你能忍受史蒂夫，他一定会让你变得更优秀。
+ 对表现不佳的人，团队有义务把他开掉；对表现出色的人，他有义务保持忠诚。

### 2.4、愿景、讲故事与直觉：把技术带给普通人

**核心：改变世界的渴望需要靠讲故事和营销落地，同时要相信直觉、随时准备好迎接运气。**

+ 他想创建的不仅是一家企业，而是胸怀改变世界的强烈渴望；从第一天起就希望技术能改善每个人的生活。
+ 只有那些疯狂到以为自己能够改变世界的人，才能真正地改变世界。
+ 如果缺乏卓越的讲故事的能力，再宏大的目标都无济于事。
+ 优秀的营销人员必须用通俗的语言解释高深的概念；技术要靠营销才能从工作台走进企业和家庭。
+ 他总能用简洁的语言描绘前景未明的技术，让观众产生强烈渴望。
+ 运气只垂青有准备的人；出乎意料的事总会发生，关键是你如何应对。

## 三、总结

《乔布斯传》我读了三遍，每次都读的津津有味。这本书却让我一度读不下去，因为他没有前者那么有趣。但是读完之后，也能从另一个角度认识乔布斯。

对我而言，最重要的观点有以下两个：

### 1. 技术要靠营销才能从工作台走进企业和家庭

作为程序员的我，应该走出开发相关的舒适区，花更多的时间在需求挖掘和营销推广上；按照哥飞老师的建议，需求挖掘、编码实现、营销推广的比例应该是 **4、2、4**，即 40% 的时间花在需求挖掘上，40% 的时间花在营销推广上，最后 20% 的时间才应该花在编码实现上。

### 2. 完美是一个渐进持续的过程，永远都不可能彻底完成

还是以 web 出海为例，很多时候，流量的窗口期是有限的，不可能等你全部准备好。我们应该在第一时间把落地页上了，然后再不断迭代，抛弃完美主义，不要过早优化。
