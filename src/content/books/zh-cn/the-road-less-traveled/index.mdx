## 一、概述

《少有人走的路：心智成熟的旅程》是美国心理医生 M.斯科特·派克的经典著作，仅在北美销量就超过700万册，被翻译成23种以上的语言，并在《纽约时报》畅销书榜单上停驻近20年，创造了出版史上长盛不衰的纪录。

全书从开篇的“人生苦难重重”切入，指出人生是一场艰辛之旅，心智成熟则是漫长而毕生的任务。作者并未让读者对苦难感到恐惧，而是通过充满沟通与理解的剖析，带领读者直面问题，经历一系列艰难乃至痛苦的转变，最终找到真正的自我，达到自我认知的更高境界。

## 二、金句摘抄

### 2.1、直面问题与自律：心智成熟的核心工具

**核心：人生是一个不断面对并解决问题的过程，遵循推迟满足感、承担责任、忠于事实和保持平衡四大自律原则，是消除人生痛苦、解决问题的根本方法。**

+ 人生是一个不断面对问题并解决问题的过程。一切心智成熟者，他们的人生之旅都是从直面问题开始。
+ 你不解决问题，你就会成为问题。
+ 回避问题和逃避痛苦的倾向，是人类心理疾病的根源。
+ 自律有四个原则：推迟满足感、承担责任、忠于事实、保持平衡。
+ 我们越是了解事实，处理问题就越是得心应手；对事实了解得越少，思维就越是混乱。
+ 抱着残缺的人生地图不放，与现实世界处处脱节，这是不少人的通病，也是造成诸多心理疾病的根源。
+ 从来不会生气的人，注定终生遭受欺凌和压制，直至被摧毁和消灭。我们要善于以不同的方式，恰当地表达生气的情绪：有时需要委婉，有时需要直接；有时需要心平气和，有时不妨火冒三丈。
+ 保持平衡的最高原则就是“放弃”。只有放弃旧的、过时的观念和习惯，才能渡过危机，顺利进入人生的下一阶段。

### 2.2、真正的爱：驱动自律与自我完善的原动力

**核心：爱不是转瞬即逝的感觉、寄生的依赖或盲目的自我牺牲，而是为了促进自己和他人心智成熟，克服懒惰与恐惧、不断拓展自我界限并付诸行动的意愿。**

+ 爱，是为了促进自己和他人心智成熟，而不断拓展自我界限，实现自我完善的一种意愿。
+ 想让别人真正爱你，只有让自己成为值得爱的人。满脑子想的只是消极接受别人的爱，就不可能成为值得爱的人。
+ 真正的爱，不是单纯的给予，还包括适当的拒绝、及时的赞美、得体的批评、恰当的争论、必要的鼓励、温柔的安慰和有效的敦促。
+ 越俎代庖地去照顾原本有能力照顾自己的人，只会使对方产生更大的依赖性，这就是对爱的滥用。
+ 真正的爱能够使人发生改变，在本质上是一种自我扩展，而非纯粹的自我牺牲。不爱自己的人，绝不可能去爱别人。
+ 想让别人听你的话，就要采用对方能理解的语言；想让别人满足你的要求，要求内容就不能超过对方承受的限度；想让对方有所进步，首先就要进行自我完善，这样才能找到沟通的最佳契机和方式。
+ 爱的重要特征之一在于，爱者与被爱者都不是对方的附属品。付出真爱的人，应该永远把爱的对象视为独立的个体，永远尊重对方的独立和成长。
+ 只有持久的情感关系，才能使心智不断成熟，而承诺能够使情感关系更加牢固稳定。所有建立在真爱之上的情感关系，其实都是互相勉励、共同促进的心理治疗关系。

### 2.3、信仰重塑与接纳恩典：精神世界的终极进化

**核心：走出童年与原生家庭的经验限制，以理性与怀疑精神重塑世界观，并在直面未知风险与孤独的过程中唤醒潜意识的智慧、接纳生命的恩典。**

+ 深入心灵，是一段艰难的旅程，也是一条少有人走的路。
+ 心灵力量的不断积聚，会带来孤独感。所有走在最前面走得最远的人，都会感受到这种孤独。
+ 人生唯一的安全感，来自于充分体验人生的不安全感。
+ 勇气，并不意味着永不恐惧，而是面对恐惧时能够坦然行动，克服畏缩心理，大步走向未知的未来。
+ 形成信仰的基本因素来自我们成长的家庭环境，许多成年人的信仰，其实正是移情的产物。要建立与现实相适应的信仰与世界观，我们必须不断学习，增进对世界的认识。
+ 只有学习和进步，才能摆脱昔日经验的限制；只有怀疑和挑战，才能使我们走上神圣的自由之路。
+ 我们之所以能具备爱的能力和成长的意愿，不仅取决于童年时父母爱的滋养，也取决于我们一生中对恩典的接纳。
+ 在教育别人的时候，并不是在把某种新的东西强塞入他们的思维，而是把这种东西从他们思维中引导出来，让它从潜意识进入意识。

## 三、总结

这是一本关于心智成熟的书，对我来说，最重要的是关于处理问题。

我总是习惯于逃避工作和生活中的问题，像只鸵鸟一样把头埋进沙子里，以为我不抬头问题就不再会有。

可是如果问题不去解决，它就一直在那里，总会在那里。而且很多小问题总会在某个时间点集体爆发，届时将更难处理。

正如段永平所说，不要把重要的事拖成紧急的事。现在的我，正值壮年，职业和生活都有重要的事情，每天都应该把重要的事情向前推进。
